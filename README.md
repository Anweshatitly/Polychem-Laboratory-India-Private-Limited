## 🚀 How to Upload to GitHub & Go Live (Step by Step)

### Step 1 — Create GitHub Account
Go to **https://github.com** → Sign Up (free)

### Step 2 — Create a New Repository
1. Click **"+"** (top right) → **"New repository"**
2. Repository name: `polychem-website`
3. Set visibility to **Public**
4. Click **"Create repository"**

### Step 3 — Upload All Files (Keep folder structure!)
1. In your new repo, click **"uploading an existing file"**
2. Open your `Polychem-Website` folder on your computer
3. Select **ALL files and folders** (`index.html`, `README.md`, the `assets` folder, the `produscts` folder)
4. Drag them all into the GitHub upload area
5. Scroll down → click **"Commit changes"**

### Step 4 — Enable GitHub Pages
1. Go to your repo → click **"Settings"** tab
2. Left sidebar → click **"Pages"**
3. Under **Source / Branch** → select `main`, folder `/` (root)
4. Click **"Save"**
5. Wait ~2 minutes. Your site will be live at:

```
https://YOUR-GITHUB-USERNAME.github.io/polychem-website/
```
